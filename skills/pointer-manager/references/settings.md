# Pointer 设置参考

**打开方式**：账户菜单（侧栏左下角头像）→ **设置**（齿轮）。侧栏工作台另有快捷入口：**定时任务** / **技能** / **连接**（同样仅管理员可见）。

> **桌面客户端始终可以打开**。网页 / 服务器部署（接入控制平台的多租户场景）仍只对**平台管理员**开放，非管理员点击不会打开（日志提示 `settings stayed closed`）。

**交互方式**：左侧分组导航，右侧内容。设置项**改完即自动保存**，**没有底部「保存」按钮**；只有「新增 / 编辑」类弹窗（服务商、MCP 服务、定时任务、Webhook 来源）里才有 **保存 / 创建** 按钮。

## 智能体

档位统一为 **快速 / 标准 / 高级**（由低到高：速度从高到低，价格从低到高，智能从低到高）。

| 区块 | 内容 |
|------|------|
| 场景档位 · 智能体配置 | **通用助手** / **氛围编程** / **电脑操控** 各选一档；每行右侧 **模型** 按钮可改该智能体各档位对应的模型 |
| 场景档位 · 媒体理解 | **图片** / **语音** / **视频** 各选一档 |
| 场景档位 · 更多工具 | **联网搜索**（点「更多」进入） |
| 场景档位 · 更多智能体 | 代码探索、通用执行、深度研究等其他执行智能体 |
| 个性化 | 写入每次对话的系统提示（`[USER RULES]`）；留空则只用产品默认规则 |

**电脑操控 · 高级模型**（电脑操控行点「更多」打开弹窗）：

| 项 | 说明 |
|----|------|
| 定位 | 元素定位所用模型，留空跟随主模型 |
| 定位校验 | 定位出框后的复核模型与思考强度，留空跟随定位 |
| 动作校验 | 动作执行后的成败校验模型与思考预算 |

## 模型配置

服务商列表（平台默认 / 已覆盖），可新增或编辑：名称、Base URL、API Key、模型名。编辑保存后该服务商归入用户层（平台注入项编辑 = 复制到用户层）。

## 系统设置

| 区块 | 项 |
|------|-----|
| 界面显示 | 界面语言（切换立即生效）、工具调用、智能体输出、显示推理过程、显示任务板、显示子 Agent 边框面板、显示子任务板、默认收缩执行过程 |
| 通知 | **完成时播放提示音**（对话回合结束时播放短促提示音） |
| 桌面自动化 | 人性化鼠标移动、**自动切换屏幕**（默认主屏，打开应用后跟随窗口所在显示器）、执行时收缩为状态条 |
| 媒体生成 | 图片生成 / 视频生成 |
| 运行环境 | **多媒体理解**（检测/安装本机 ffmpeg）、**终端环境变量**（KEY→VALUE 覆盖，优先级最高） |
| 执行 | 工具并行、通用工具、子 Agent（本会话同时运行上限，含后台终端）、媒体工具、轮次（本轮 / 子任务，子任务上限 500）、任务并行（同时任务数）、查看队列 |
| 内容上限 | 上传（MB）、正文（KB）、单行（字节）、搜索条数、终端（KB）、终端超时（空闲秒 1–86400 / 最长运行 1–10000 小时） |
| 工具使用权限 | **自动执行** / **敏感操作确认** |

## 自动化

| 区块 | 内容 |
|------|------|
| 定时任务 | 新建（名称 / 智能体 / 调度 / 触发提示词）；启用停用、修改投递目标、查看会话。一次性任务执行后保留为已完成，不可重新启用 |
| Webhook 调用 | 每个来源独立 Token（须与 URL 路径中的来源标识匹配）；鉴权 Header；会话模式（按投递隔离 / 按日续接）；`blocking: true` 可同步等待结果 |
| 投递 | 开启后把最终回复推到所选通道。每个通道对应**最近一次私聊 Pointer 的人**，未绑定的通道需先私聊一次 |

## 连接（IM 通道）

Tab 顺序：**微信 → 飞书 → 企微 → 钉钉**。每个 Tab 标题下有模式徽标：微信 = iLink 长轮询，飞书 / 企微 = **WSS 长连接**，钉钉 = Stream 长连接；右侧 **启用** 开关。

**扫码流程：** 点 **扫码连接** → 出二维码 → 用户手机 App 扫码授权 → **自动连接** → 状态「运行中，可正常收发消息」。手填凭证则需再点 **连接**。

| 通道 | 扫码提示 | 备注 |
|------|----------|------|
| 微信 | 使用微信 App 扫描，手机上确认登录 | 仅桌面客户端可扫码；无手填凭证、无 Webhook |
| 飞书 | 使用飞书 App 扫描，按提示完成应用授权 | 后台需选「长连接接收事件」并订阅 `im.message.receive_v1` |
| 企微 | 使用企业微信 App 扫描，点「一键创建智能机器人」 | 手填需 Bot ID + 应用 Secret + WSS 地址（留空用 `wss://openws.work.weixin.qq.com`） |
| 钉钉 | 使用钉钉 App 扫描，点「一键创建新机器人」 | Stream 长连接；群聊需 @ 机器人 |

**高级设置（Webhook 备选）**：默认走长连接，仅在需要 HTTP 回调时勾选「启用 HTTP 回调」（企微为 Agent 模式，需 Corp ID / Agent ID / Secret / Token / EncodingAESKey），并填 **公网 Base URL**。

**通用设置**（对所有通道生效）：

| 项 | 说明 |
|----|------|
| IM 出站推送 | 中间文字、工具调用（只推「开始调用」，不推完成/失败） |
| 会话重置 | 空闲自动重置，默认 60 分钟，0 = 关闭；IM 里发 `/new`、`/reset`、`新对话` 可手动开新会话 |
| 公网 Base URL | Webhook 模式生成回调地址用 |
| 配对审批 | 输入 8 位配对码 → **批准**（自动识别通道） |

## 技能 / 插件 / MCP

| 分区 | 内容 |
|------|------|
| 技能 | 启用/停用、导入、查看已装技能 |
| 插件 | 从目录或 zip 导入（自动识别 Pointer / Codex / Claude 插件）；状态：未授权 / 校验失败 / 已启用 / 已禁用 / 需重新授权 / 运行异常；可卸载 |
| MCP | 外部工具服务（命令或 URL 两种接入）；状态：正常 / 已中断 / 运行异常 / 未启用 |

| 分区 | 内容 |
|------|------|
| 云主机 | 需登录账户；余额、去充值；试用 / 按时 / 包月 / 包年 |

## 账户与外观（不在设置里）

账户菜单（侧栏左下角头像）单独承载：登录状态、**登录 / 退出登录**、余额与充值、**外观**（浅色 / 深色 / 跟随系统）、检查更新、**设置** 入口。

## 不要进入

调试分区内的模型映射子项（各模式对应模型 / 电脑操控各模式对应模型 / 多媒体理解各模式对应模型）——面向排障，改错会直接影响主流程。
