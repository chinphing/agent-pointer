# 两张图怎么分工

给你两张图，都是**以参考框为中心**从屏幕上裁下来的（不是整屏）。**图里画着参考框** —— 一个矩形，框线是一圈细实线；参考框的正中画着一个红点（实心红圆，边缘带一圈很细的白边）。参考框是候选位置，在两张图里都位于正中央。

- **图一（小图）**：裁剪范围小，目标在图里显得**大**、看得**清**。
- **图二（大图）**：裁剪范围是图一的 4 倍，输出尺寸一样，所以目标在图里显得**小**，但能看到更远的周围。

## 1. 固定顺序：先图二定行列，再图一判框

不要跳步。

## 2. 第一步 —— 看图二，确认目标在哪一行、哪一列

图二能看到完整的行标/列标、盘面或表格的行列起始位置、更远的锚点（「数字 8 的右边」里的那个 8 可能只在图二里看得见）。

- 先在图二里找到行标/列标（字母、数字、序号），用它确认目标的行号和列号；
- 如果锚点在图一里看不到，去图二里找；
- **把结论写进 `position.remark` 的最前面**，例如「图二：列标 7/8/9 可见，目标在第 8 列；行标 G/H 可见，第 8 行」。
- 如果图二里确实没有任何行列标、也没有锚点，就明确写「图二无行列标」，然后跳过这一步。**不要因为看不到就编一个行列号。**

## 3. 第二步 —— 回到图一，判断框对不对

框里是什么、目标的轮廓/边线在哪、框有没有包住四条边线、框比目标大多少——全部只看图一。图一里目标最大最清楚，这些判断只有它靠得住。

用第一步确认的行列号，核对「图一里框住的这个元素」和「图二里确认的那个元素」是不是同一个。**如果两者不一致，说明框错了，`position.ok = no`。**

**图二绝不能用来判「框压没压住边线」「框大了多少」**——图二里目标太小，看这些必错。

## 4. position.remark 要写清两件事

① 你在图二里看到的行列标或锚点（看不到就直说「图二无行标」）；② 框在图一里框住的是哪个元素。

- 图二看不到行标时，直接写「图二无行标」，不要改用盘面内容反推行号——反推出来的行号不可信。
- 图二能看到行标/列标时，把看到的具体值写出来（「列标 7/8/9 可见，行标 G/H 可见」）。
- 图二里的行列标只看到一部分、读不出绝对位置时，`position.ok` 填 unknown，不要猜。
- 描述里给了周边锚点（「在 X 右边」）时，说清图二里那个锚点在不在、指向哪个元素。

例：`列标7/8/9可见、行标G/H可见；框在图一里是白色区域，倍数约1.1`。
