Search prior conversations in this app.

**When to call**
- You need earlier user details not in the current history window.
- Scroll mode: set `conversation_id` + `around_message_id`.

**When not to call**
- Current injected history already has the facts.
- Sub-task with only goal/context (prefer anchor attachments).

**Note**
- Prefer the history already provided; current session scroll may be limited.
