# Webhook automation

English | [简体中文](../../zh-CN/user/webhook.md)

Trigger Pointer Agent over HTTP from CI, scripts, or external systems, optionally with attachments.

## Prerequisites

- A **Pointer server** that is deployed and exposes a public address (cloud host or self-hosted instance)
- In **Settings → Automation → Webhook**, add a source (e.g. `ci`) and note the **source id** and **Token**

**LLM credentials (no need to log in from curl):**

- **Cloud host**: first complete a one-time OAuth via **Open cloud host** on the desktop (credentials are stored on the server and reused by Webhook / scheduled tasks). After that, curl only needs the Webhook Token and does not have to carry a browser cookie.
- **Self-hosted server**: configure the DashScope API Key in **Settings**; no account login is required.
- The Webhook Bearer Token only decides "triggering is allowed"; it does not handle LLM authentication.

**About saving the Token:**

- The list shows only the trailing characters (e.g. `****1d34`); click to copy the full Token (an account login is required).
- When you add a source, the Token is also copied to the clipboard automatically.
- If you lose the Token: delete the source and add it again (the Token can be set only once and cannot be overwritten).

The same source continues the same conversation within a local calendar day (switching at 04:00); across days a new conversation starts automatically.

## Call flow

1. **Upload attachments** (optional, multiple supported): `POST /api/webhooks/<source>/upload`
2. **Trigger the Agent**: `POST /api/webhooks/<source>`, with the request body carrying the description text and attachment references
3. Set `blocking: true` to wait synchronously for the Agent reply; by default it returns a `runId` asynchronously

For large files, upload first and then reference them; do not stuff files into JSON. The per-file upload limit is **30 MiB**.

For the full API reference see **[`../developer/webhook-api.md`](../developer/webhook-api.md)**.

## Python example

Dependencies:

```bash
pip install requests
```

Script (multiple attachments supported; configure the domain, source id, and Token at the top):

```python
#!/usr/bin/env python3
"""
Pointer Webhook call example (multiple attachments supported)
- Input: description text, optionally several attachment paths
- Output: the Agent's synchronous reply (blocking mode)
"""

from __future__ import annotations

import argparse
import json
import mimetypes
import sys
from pathlib import Path
from typing import Any

import requests

# ============ Configure here ============
WEBHOOK_HOST = "https://your-pointer-host"  # public address of the Pointer server, without the trailing /
WEBHOOK_SRC = "ci"                          # source id configured in the automation panel
WEBHOOK_TOKEN = "your-token-here"           # Token generated by the panel
TIMEOUT_SECONDS = 300                       # longest synchronous wait for the Agent (max 600)
# =================================


class PointerWebhookError(Exception):
    pass


def _headers() -> dict[str, str]:
    return {
        "Authorization": f"Bearer {WEBHOOK_TOKEN}",
    }


def _raise_for_status(resp: requests.Response, action: str) -> None:
    if resp.ok:
        return
    detail = resp.text.strip() or resp.reason
    raise PointerWebhookError(f"{action} failed ({resp.status_code}): {detail}")


def upload_attachment(file_path: Path, conversation_id: str | None = None) -> dict[str, Any]:
    """POST /api/webhooks/:src/upload"""
    if not file_path.is_file():
        raise PointerWebhookError(f"attachment not found: {file_path}")

    mime_type, _ = mimetypes.guess_type(file_path.name)
    data: dict[str, str] = {}
    if conversation_id:
        data["conversationId"] = conversation_id

    with file_path.open("rb") as f:
        files = {
            "file": (file_path.name, f, mime_type or "application/octet-stream"),
        }
        resp = requests.post(
            f"{WEBHOOK_HOST}/api/webhooks/{WEBHOOK_SRC}/upload",
            headers=_headers(),
            data=data,
            files=files,
            timeout=120,
        )

    _raise_for_status(resp, f"upload {file_path.name}")
    return resp.json()


def upload_attachments(file_paths: list[Path]) -> tuple[str, list[dict[str, Any]]]:
    """Upload multiple files, reusing the same conversation conversationId."""
    if not file_paths:
        return "", []

    conversation_id: str | None = None
    attachments: list[dict[str, Any]] = []

    for file_path in file_paths:
        uploaded = upload_attachment(file_path, conversation_id=conversation_id)
        conversation_id = uploaded["conversationId"]
        attachments.append(
            {
                "id": uploaded["attachmentId"],
                "kind": uploaded["kind"],
                "mimeType": uploaded["mimeType"],
                "fileName": uploaded["fileName"],
                "storageRelPath": uploaded["storageRelPath"],
            }
        )

    return conversation_id or "", attachments


def trigger_webhook(
    description: str,
    attachments: list[dict[str, Any]] | None = None,
    conversation_id: str | None = None,
) -> dict[str, Any]:
    """POST /api/webhooks/:src (blocking=true waits for the result synchronously)"""
    payload: dict[str, Any] = {
        "text": description,
        "blocking": True,
        "timeoutSeconds": TIMEOUT_SECONDS,
    }
    if conversation_id:
        payload["conversationId"] = conversation_id
    if attachments:
        payload["attachments"] = attachments

    resp = requests.post(
        f"{WEBHOOK_HOST}/api/webhooks/{WEBHOOK_SRC}",
        headers={**_headers(), "Content-Type": "application/json"},
        json=payload,
        timeout=TIMEOUT_SECONDS + 30,
    )

    _raise_for_status(resp, "trigger")
    return resp.json()


def call_pointer_webhook(
    description: str,
    attachment_paths: list[str] | None = None,
) -> dict[str, Any]:
    """
    Main flow: optionally upload multiple attachments -> trigger the Agent -> return the result

    Example response on success:
    {
      "ok": true,
      "runId": "...",
      "conversationId": "webhook:ci:20260708",
      "text": "the Agent's final reply"
    }
    """
    conversation_id: str | None = None
    attachments: list[dict[str, Any]] | None = None

    if attachment_paths:
        paths = [Path(p) for p in attachment_paths]
        conversation_id, attachments = upload_attachments(paths)

    return trigger_webhook(
        description=description,
        attachments=attachments,
        conversation_id=conversation_id,
    )


def main() -> int:
    parser = argparse.ArgumentParser(
        description="Call Pointer webhook with text and optional attachments",
    )
    parser.add_argument("description", help="task description sent to the Agent")
    parser.add_argument(
        "-a", "--attachment",
        dest="attachment_paths",
        action="append",
        default=[],
        help="local attachment path; can be repeated: -a a.pdf -a b.xlsx",
    )
    args = parser.parse_args()

    try:
        result = call_pointer_webhook(args.description, args.attachment_paths or None)
    except PointerWebhookError as e:
        print(f"Error: {e}", file=sys.stderr)
        return 1
    except requests.RequestException as e:
        print(f"Network error: {e}", file=sys.stderr)
        return 1

    print(json.dumps(result, ensure_ascii=False, indent=2))
    print("\n--- Agent Reply ---\n")
    print(result.get("text", ""))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Command-line usage

```bash
# Text only
python pointer_webhook_example.py "Please summarize today's build status"

# A single attachment
python pointer_webhook_example.py "Please analyze this report" -a ./report.pdf

# Multiple attachments
python pointer_webhook_example.py "Compare these two documents" \
  -a ./report_v1.pdf \
  -a ./report_v2.pdf \
  -a ./summary.xlsx
```

## Calling from code

```python
result = call_pointer_webhook(
    "Please summarize these attachments",
    attachment_paths=["./a.pdf", "./b.png", "./c.xlsx"],
)
print(result["text"])
```

## FAQ

| Symptom | Handling |
| --- | --- |
| 401 | Check whether the Token and source id match those in the automation panel |
| Please log in first / LLM credentials required | Cloud instance: complete one login via desktop "Open cloud host"; self-hosted: configure the API Key in Settings |
| Token unavailable | Make sure an account is logged in; delete the source and add it again |
| 504 | Increase `TIMEOUT_SECONDS` (max 600), or switch to asynchronous (`blocking: false`) |
| Attachment not found | Upload first, then use the returned `storageRelPath` when triggering, and keep the same `conversationId` |
| 413 | A single file exceeds 30 MiB; split it or use another transfer method |

If the source is configured with a custom auth Header (not `Authorization`), change `_headers()` in the script to the corresponding header name and raw Token value.
