# 定位任务（重找）

## 目标元素描述

{desc}

## 坐标要求

用**这张图自己的** 0–1000 刻度：左上角 (0,0)，右下角 (1000,1000)。

## 判定：先认，再框

两个问题，**顺序不能反**：

1. **满足描述条件的目标，在这张图里吗？**
2. 在 → 框出它；不在 → `found = false`。

**跳过第一个问题直接给框，是这类任务最常见的错误。**

## 步骤

### 第一步：把描述拆成可核对的条目

| 类型 | 例子 | 怎么用 |
|---|---|---|
| 外观 | 「浅灰色铅笔形状图标」「无文字」 | 逐项核对 |
| 相对位置 | 「列表图标右边第一个」「紧挨着 ×」 | 看图里的邻居 |
| 绝对位置 | 「屏幕中左」「盘面 E7」「第 3 行第 6 列」 | **跳过**，图上没有这类标注 |

### 第二步：按外观扫一遍，列出候选

**一个外观相符的都没有 → 直接到第四步。**

### 第三步：逐条核对候选

判据有强弱，**不是每一条都有否决权**：

| 强度 | 条目 | 对不上怎么办 |
|---|---|---|
| 强 | 位置锚点（「Add 菜单文字右端」「显示格式正上方」） | 换下一个候选 |
| 强 | 文字、图标含义（形状、符号） | 换下一个候选 |
| 弱 | 底色、边框、是否高亮、大小 | **不能单独否决**，记下来继续看别的条目 |

**「无底色无边框」这类描述往往只是指「没被选中」。** 界面里被选中的元素会加蓝框、浅色底，那不是另一个元素，是同一个元素的另一种状态。

**只有当强判据对不上时才换候选。** 弱判据对不上、强判据全对 → 这就是目标，框它。

### 第四步：决定

| | 输出 |
|---|---|
| 在 | `found = true` + 它的四条边 |
| 不在 | `found = false`，不给框 |

## 框怎么画

四条边**贴着目标自己的轮廓**：不留余量，也不缩进到目标内部。目标比框大出 {size_max} 倍以上，说明框错了。

## 为什么 `found = false` 不算失败

图里没有描述的那个东西时，说 `false` 是正确答案：调用方会换一张图重找，代价只是一次调用。给一个错框，错误会送到用户手里。
