# Pointer 设置参考

打开方式：侧栏底部 **设置**（齿轮）→ 左侧选菜单 → 底部 **保存**。

## 智能体

| 区块 | 项 |
|------|-----|
| 模式选择 | 智能体（电脑操控 / 通用助手 / 氛围编程）、工具（图片 / 语音 / 视频理解）；模式为快速 / 标准 / 专家 |
| 电脑操控选项 | 人性化鼠标移动、滑块终点偏移、执行时收缩为状态条 |
| 工具使用权限 | 自动执行 / 敏感操作确认 |
| 个性化 | 写入每次对话的系统提示 |

## 系统设置

| 区块 | 项 |
|------|-----|
| 执行 | 任务并行、工具并行、轮次（本轮 / 子任务上限） |
| 内容上限 | 上传、读文件、搜索和终端输出回给 AI 的上限 |

## IM 通道

Tab 顺序：微信 → 飞书 → 企微 → 钉钉。默认长连接，无需公网。

**扫码流程：** 开始扫码 → 用户手机/弹窗授权 → **自动连接** → 状态「运行中，可正常收发消息」。

| 通道 | 注意 |
|------|------|
| 微信 | 仅桌面客户端可扫码 |
| 飞书 | 后台需选「长连接接收事件」+ 订阅 `im.message.receive_v1` |
| 企微 | 点扫码弹出独立窗口；WSS 默认即可 |
| 钉钉 | Stream 长连接；群聊需 @ 机器人 |

手填凭证后需点 **连接**。折叠区：**配对审批**（输入配对码 → 批准）、手动填凭证。

## 账户

**浏览器登录** 完成 OAuth（或独立部署账号密码）；**退出登录** 清除会话。

| 区块 | 项 |
|------|-----|
| 通知 | **完成时播放提示音**：对话回合结束时播放短促提示音（默认开启；切换后立即保存） |

## 不要进入

调试模式（标题栏虫子图标）及其菜单：模型服务、界面配置、智能模式。
