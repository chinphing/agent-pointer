# 管理端界面线框图

**改界面前先看图**；实现与图不一致时，先确认是「有意裁剪」还是「漏做」，
再把结论回写到 [`enterprise-admin-console.md`](../enterprise-admin-console.md) §9。

## 已知的有意裁剪（M0）

- 档位映射只下发一条 `tier_profile`，不做「锁定档位」（图 8 自己也标注了）；
- 不开放自定义角色，权限矩阵只读展示（图 4 标注「内置角色权限固定」）；
- 概览的趋势图与「最近操作」尚未实现。
