# 管理端界面线框图

设计阶段的线框图（SVG，`viewBox` 固定，可直接在浏览器或编辑器打开）。
**改界面前先看图**；实现与图不一致时，先确认是「有意裁剪」还是「漏做」，
再把结论回写到 [`enterprise-admin-console.md`](../enterprise-admin-console.md) §9。

| 文件 | 内容 |
| --- | --- |
| `01_管理端登录页.svg` | 登录卡片：账号 / 密码 / 验证码 / 首次部署提示 |
| `02_管理端概览页.svg` | 侧边栏 + 4 张统计卡 + 7 日趋势 + 最近操作 + 资源总览 |
| `03_资源管理页.svg` | 类型页签 + 搜索 + 状态/可见范围筛选 + 分页 + 表格列 |
| `04_角色与权限页.svg` | 内置/自定义角色 + 模块 × 动作权限矩阵 |
| `05_资源详情抽屉.svg` | 右侧抽屉：状态、可见范围 chips、版本历史、已授权 |
| `06_单技能授权_详情抽屉与授权浮层.svg` | 授权浮层：按角色/按成员 + 搜索 + 勾选 + chips 混排 |

| `09_档位映射配置页_含思考强度_.svg` | 同上，每档增加思考强度 |

## 配色（取自客户端 `src/styles/globals.css`）

| 用途 | 取值 |
| --- | --- |
| 页面底色 | `#FAFAFA` |
| 面板 / 卡片 | `#FFFFFF` |
| 侧边栏 | `#F2F2F4` |
| 正文 | `#18181B` |
| 次要文字 | `#71717A` |
| 描边 | `#E5E5E8` |
| 输入框描边 | `#D4D4D8` |
| 主色 | `#0071EB` |

圆角：控件 8px，卡片 10–14px。基准字号 12–14px。

## 实现状态

九张图全部实现：

- 图 01 登录（含验证码）
- 图 02 概览（7 日趋势柱状图 + 最近操作）
- 图 03/05 资源列表（搜索/筛选/分页/授权选择器/建时可见范围/测试连接）与详情抽屉
- 图 04 角色与权限（自定义角色 + 模块×动作矩阵）
- 图 08/09 档位映射（场景 × 三档矩阵、每格思考强度、锁定档位开关）

「锁定档位」需要客户端配合，已在客户端 `AssistantSettingsPanel.vue` 实现并真机验证：
锁定后六个场景的档位按钮灰化、点击无效，并显示「企业已锁定档位，员工不可修改」。
