# 云主机

[English](../../en/user/cloud-host.md) | 简体中文

云主机是**平台帮你跑起来的一台完整 `pointer-server`**。你在桌面端点「打开」，它就用一个独立窗口连过去 —— 相当于把服务端和 Web 版整个搬到云上，本机不用一直开着。

```
你的桌面端                        平台 ECS
┌──────────────┐   签发一次性 code  ┌────────────────────┐
│ 设置 → 云主机 │ ─────────────────▶ │ pointer-server     │
│  购买 / 续费   │                   │ （完整 Web 版）     │
│  打开 ────────┼── 独立窗口 ──────▶ │ 对话 / 附件 / 技能  │
└──────────────┘                   └────────────────────┘
```

## 什么时候能看到这个入口

| 你的情况 | 设置里有「云主机」吗 |
| --- | --- |
| **桌面端** + 已绑定控制面（非独立部署） | 有 |
| Web 端（浏览器里） | **没有** |
| 独立部署（standalone） | **没有** |

也就是说，这个分区只在**桌面客户端**上出现，而且只对绑定了控制面的构建出现。看不到不代表坏了。

## 前提：先登录平台账号

没登录时，这个分区只有一句提示和一个按钮：

> 登录账户后可管理云主机　　[ 浏览器登录 ]

点「浏览器登录」走平台账号登录流程。登录之后才会加载余额和实例列表 —— 未登录时不会发任何云主机请求。

## 余额与充值

登录后顶部显示「**余额 {金额} 元**」和「**充值**」按钮，充值会打开平台的账单页。

余额不够时相关操作会直接失败，并在错误条里给一个「**去充值**」的快捷入口。要提前充就去平台账单页。

## 买一台

点「**购买云主机**」：

| 字段 | 说明 |
| --- | --- |
| **部署地域** | 选实例落在哪个区域 |
| **套餐类型** | 四选一，见下表 |
| **购买时长** | 按套餐单位填（小时 / 月 / 年），最小 1 |
| **应付金额** | 填完时长自动算价；下面还会显示「当前余额 {金额} 元」 |

| 套餐类型 | 计费单位 | 适合 |
| --- | --- | --- |
| **试用** | 元 / 小时 | 先试一下，按小时算 |
| **标准按时** | 元 / 小时 | 短时间、不确定用多久 |
| **包月** | 元 / 月 | 长期跑 |
| **包年** | 元 / 年 | 长期跑，摊下来更便宜 |

金额区域会显示「计算中…」；时长没填有效值时显示「填写有效时长后自动计算」。有优惠时还会多一行「已优惠 {金额} 元（{百分比}%）」。

确认前请核对地域、套餐和金额 —— 点「**确认购买**」就是**确认扣款并创建实例**。

## 实例卡片

每台实例一张卡：

| 位置 | 内容 |
| --- | --- |
| 标题 | 地域名；没有地域信息时显示「云主机」 |
| 到期 | 「到期 {时间}」 |
| 状态徽标 | 运行中 / 启动中 / 释放中 / 已释放 / 启动失败 / 异常 |
| 探活错误 | 有的话以红字显示原因 |
| 按钮 | 见下 |

| 按钮 | 什么时候有 | 行为 |
| --- | --- | --- |
| **打开** | 实例真正就绪时 | 开一个独立窗口连过去（下面详述） |
| **切换到云窗口** | 窗口已经开着 | 把云窗口聚焦到前台 |
| **关闭云窗口** | 窗口已经开着 | 关掉窗口（**不影响实例**，实例还在跑） |
| **续费** | 状态是运行中 | 打开续费弹窗，沿用当前套餐类型与时长参数，确认后扣款 |
| **释放** | 未释放的实例 | 打开释放确认 |

实例列表可以用状态筛选：**运行中 / 启动中 / 已释放 / 全部**。

> **释放是不可逆的。** 确认框写得很直白：「释放后实例将被销毁，数据无法恢复。」释放成功后云窗口也会自动关闭。

## 打开之后是什么

点「打开」后：

1. 桌面端向平台要一个**一次性的 code**
2. 用这个 code 打开一个**独立窗口**（标题是「Pointer · {地域}」），加载这台实例自己的地址
3. 实例上的 `pointer-server` 用 code 换到登录态，转到它的首页

所以云窗口里就是**完整的 Web 版 Pointer** —— 对话、附件、技能、查看桌面都在，和你在浏览器里访问一台自建服务端是同一套界面。

云窗口和主窗口是两个窗口：关掉云窗口不会停实例，下次点「打开」再连即可。

## 已知限制

- **购买时不能挑机器档位**：套餐和时长可选，机器规格目前自动取平台默认档
- **停机保数据未实现**：目前没有「停掉实例但保留数据」的操作（开发者文档里标为后续阶段）
- **主界面 Tab 未实现**：本地与云主机不能在同一个窗口里切换标签，现在是独立多窗口

## 常见问题

**「请先登录 Pointer 平台账户」**

没登录。点分区里的「浏览器登录」，或在左下角「账户」菜单登录。

**「账户余额已用尽」/「账户余额不足」**

余额不够。点「去充值」，或到平台账单页充值。

**「平台登录已失效，请在「账户」重新登录后再试」**

登录态过期了。在「账户」菜单重新登录。

**「智能体尚未就绪，无法打开」**

实例还在启动中（或者还没准备好）。等状态变成「运行中」再点「打开」。

**「云主机窗口未打开」**

对已经关掉的窗口点了「切换到云窗口」。重新点「打开」即可。

**「控制台地址无效」**

平台返回的实例地址不合法，通常是平台侧问题。刷新列表重试；仍然不行就找平台管理员。

**「当前页面无法调用桌面接口，请从主窗口打开云主机或使用浏览器直接访问」**

这个动作必须在**主窗口**里做。云窗口里加载的是远程页面，出于安全考虑调不到桌面接口 —— 要买、要续费、要释放，都回主窗口的设置里操作。

**点了「打开」但窗口一片空白**

先确认实例状态是「运行中」且没有探活错误。启动中的实例即使窗口开了也还没有可访问的页面。

**看不到「云主机」这个分区**

对照上面那张表：Web 端和独立部署都没有这个分区；桌面端要绑定控制面才有。
