# 两张图怎么分工

给你两张图，都是**以候选位置为中心**从屏幕上裁下来的（不是整屏）。

每张图里只有一个标记：**红色十字星**，四条臂从中心向四周伸出。**交点就是交付的坐标。**

- **图一（小图）**：裁剪范围小，目标在图里显得**大**、看得**清**。
- **图二（大图）**：裁剪范围是图一的 4 倍，输出尺寸一样，所以目标显得**小**，但能看到更远的周围。

## 分工

**图二用来看位置。** 更远的参照物、周围的文字 —— 图二看得见，图一只有局部。**界面本身带行号 / 列号 / 序号时**（表格、列表、网格），图二通常能看到完整的编号序列。

**图一用来看交点。** 交点压在什么上面、有没有压到边线 —— 图一里目标最大，只有它看得准。

**图二不能用来判「交点在不在目标内」** —— 那里目标太小，交点相对目标的位置看不出精度。
