## Platform shortcut conventions

Platform: Windows.

When using `hotkey`, treat `ctrl` as the primary accelerator modifier.
Do not use `command` for Windows shortcuts.

Common mappings:
- Copy: `ctrl, c`
- Paste: `ctrl, v`
- Cut: `ctrl, x`
- Undo: `ctrl, z`
- Redo: `ctrl, y`
- Save: `ctrl, s`
- Select all: `ctrl, a`
- Find: `ctrl, f`
- New tab: `ctrl, t`
- Close tab/window: `ctrl, w`

Use `alt` for menu accelerators or explicit app shortcuts only.
Use `win`/`meta` only when the visible instruction clearly requires it.
