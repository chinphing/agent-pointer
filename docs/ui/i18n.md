# UI 国际化（i18n）

Pointer 桌面端与 Web 共用 `src/`，界面语言一次迁移两端生效。

## 语言选择

| 值 | 含义 |
| --- | --- |
| `system`（默认） | 跟随系统：`navigator.language` / OS locale 以 `zh` 开头用中文，否则英文 |
| `zh-CN` | 中文 |
| `en` | English |

- 字段：`UserSettings.uiLocale`，写入 `user_settings.json`
- 设置路径：**设置 → 系统设置 → 界面语言**
- 切换后立即生效，无需重启
- 前端解析：`src/lib/uiLocale.ts` 的 `resolveUiLocale()` / `applyUiLocale()`
- Rust 解析：`pointer_core::i18n::resolve_ui_locale()`（与前端规则一致）

## 技术栈

| 层 | 方案 |
| --- | --- |
| Vue | `vue-i18n`（Composition API，`legacy: false`） |
| 文案 | `src/locales/zh-CN.json`、`src/locales/en.json` |
| 入口 | `src/i18n/index.ts`，在 `main.ts` 挂载 |
| 模板 | `$t('key')` / `t('key')` |
| 脚本 / store | `import { t } from '../i18n'`（按路径调整） |
| Rust（界面可见） | `crates/pointer-core/src/i18n/`：catalog + `t`/`tf`；按 settings locale **渲染最终串** 再发给前端 |

## Key 约定

- 点分层英文 key：`chat.composerPlaceholder`、`settings.sections.generation`
- **禁止**用中文做 key
- 插值：`{name}`（vue-i18n named；Rust `tf` 同形）
- 日期 / 数字：用 `Intl`，不要手写格式串塞进文案（除非产品固定句式）
- 模块前缀：`common.*`、`shell.*`、`chat.*`、`settings.*`、`workspace.*`、`skills.*`、`auth.*`、`agents.*`、`tools.*`、`updater.*`、`errors.*`

## 始终不翻译

- 产品名 **Pointer**
- 模型 / 通道品牌（千问、飞书、企微等）在文案中可保留品牌字形；通道选择 UI 可用本地化称呼
- 技术标识符：`API Key`、`MCP`、agent id、工具内部名

## 新增 UI 文案

1. 在 `zh-CN.json` 与 `en.json` **同时**加同一 key
2. 组件 / store 用 `t()`，不要硬编码中文或英文 UI 句
3. 跑 `npm test -- src/locales/localeParity.test.ts`（双语文案 key 对齐）
4. Rust 用户可见串走 `crate::i18n::{t,tf}`，并在 `i18n/catalogs.rs` 双侧补齐

## Rust 约定

- `current_ui_locale()` 从 `user_settings.json` 读取 `uiLocale` 并 resolve
- 工具展示名、agent 展示名、UiToast、部分命令错误：catalog 出最终串
- Agent 系统提示保持英文；通过 `push_ui_locale_reply_rule_to_cacheable` 注入短规则，要求按 UI 语言回复

## 首页 / Composer 注意点

- 输入框占位符走 `chat.composerDefault`（vue-i18n）。`index.html` / 服务端注入的
  `pointer-composer-placeholder` **不得**再写死中文默认句；仅白标定制文案可注入，
  且与产品默认中文句相同时会被忽略以便跟随界面语言。
- 智能体展示名走 `agents.*`；`AGENT.md` 的 `composerLabel` 中文仅作无 i18n key 时的回退，
  内置 `general` / `coder` / `computer` 等以当前 UI 语言为准。
- 切换语言：设置 → 系统设置 → 界面语言 → English；首页空会话占位与「General」应立即切换。

## 打包语言

桌面安装包（NSIS / DMG）与 `tauri.conf.json` 的安装向导语言属打包配置，不阻塞应用内 i18n。
