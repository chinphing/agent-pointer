# 设置总览

[English](../../en/user/settings.md) | 简体中文

Pointer 的开关几乎都在**设置**里。进设置有三条路：

| 想改什么 | 从哪进 |
| --- | --- |
| 技能 / 定时任务 / 连接 | 侧边栏「工作台」里直接点对应入口 |
| 智能体（档位、个性化） | 输入区档位弹层右上角的齿轮 |
| 完整设置（12 个分区） | 左下角「**账户**」菜单 →「**设置**」（管理员账号） |

左侧栏把 12 个分区分成三组，其中三个分区要满足条件才出现：

```
设置
├─ 智能体 · 模型配置 · 系统设置          ← 日常最常改
├─ 自动化 · 连接 · 技能 · 插件 · MCP      ← 接入与扩展
└─ 调试* · 云主机* · 用量 · 关于          ← * 满足条件才出现
```

## 12 个分区速查

| 分区 | 侧栏描述 | 管什么 |
| --- | --- | --- |
| **智能体** | 档位与行为 | 三个场景各用哪个档位、媒体理解档位、联网搜索档位、个性化规则 |
| **模型配置** | 服务商与档位映射 | 平台服务与自定义服务、参数与能力。见 [配置模型服务](model-providers.md) |
| **系统设置** | 界面、桌面与系统运行 | 界面显示、通知、桌面自动化、媒体生成、运行环境、执行、工具使用权限 |
| **自动化** | 定时任务与 Webhook | 定时任务列表与新建；Webhook 来源。见 [定时任务](scheduled-tasks.md) |
| **连接** | 微信/飞书/企微/钉钉 | IM 通道扫码或手动接入、会话重置、公网地址、配对审批 |
| **技能** | 启用与管理技能 | 按智能体启用/停用技能、来源筛选、导入 zip |
| **插件** | 管理 Pointer 插件 | 启用、授权、卸载、从目录或 ZIP 导入 |
| **MCP** | 外部工具服务 | 外部 MCP 服务的增删改、工具列表、刷新与重启 |
| **调试** | 保存对话请求 | 保存每轮请求、显示原始内容、显示 Computer 标注截图 |
| **云主机** | 购买与管理 | 余额与充值、购买、续费、释放、打开云窗口。见 [云主机](cloud-host.md) |
| **用量** | Token 消耗记录 | 按时间范围看总计与明细 |
| **关于** | 版本与更新 | 当前版本、检查更新 |

## 哪些分区会「消失」

有的分区不是人人都有 —— 看不到不是坏了，是没满足条件：

| 分区 / 按钮 | 出现条件 |
| --- | --- |
| **调试** | 平台管理员，**或**独立部署（standalone） |
| **云主机** | **桌面端**，且**不是**独立部署 |
| **关于 →「检查更新」** | **托管版**（managed）的**桌面端**；其余构建只有版本号 |

Web 端还少一块：**Webhook 调用**只在服务端 / Web 上出现，桌面端的「自动化」里没有它（见 [定时任务](scheduled-tasks.md)）。

## 智能体

**场景档位**是这一页的主角。三个场景各自独立选档，档位从低到高是 **快速 → 标准 → 高级**（速度从高到低，价格从低到高，智能从低到高）：

| 场景 | 干什么用 |
| --- | --- |
| **通用助手** | 日常对话、写作与工具调用 |
| **氛围编程** | 深度重构、跨文件修改与测试 |
| **电脑操控** | 桌面操作、浏览器自动化与文件处理 |

| 元素 | 说明 |
| --- | --- |
| 档位单选 | 每个场景一行，选中即生效 |
| **模型** 按钮 | 打开「三档模型映射」：给该场景的快速 / 标准 / 高级各指定模型与推理参数。标着「**已覆盖**」的档位表示模型被手动改过 |
| **媒体理解** | 图片理解 / 语音转写 / 视频理解，各选一个档位 |
| **更多工具 → 联网搜索** | 联网搜索各档位的模型（只列兼容的搜索模型） |
| **更多** | 其他执行智能体的档位与模型 |
| **个性化** | 一段写进每次对话系统提示（`[USER RULES]`）的规则，**最多 4000 字**；留空则只用产品默认规则 |

「个性化」适合写「只改我明确要求的行为」「歧义时先说明假设」这类长期约束 —— 它每次都进提示，所以越短越准。

## 系统设置

七个子块，都在同一页往下滚：

| 子块 | 里面有什么 |
| --- | --- |
| **界面显示** | 界面语言（跟随系统 / 中文 / English）；工具调用显示：显示 sidecar 工具调用、显示非 sidecar 工具调用、显示工具调用卡片、显示工具调用结果；智能体输出：显示推理过程、显示任务板、显示子 Agent 边框面板、显示子任务板；执行过程：执行时收缩为状态条、默认收缩执行过程 |
| **通知** | 完成时播放提示音（对话回合结束时播放短促提示音） |
| **桌面自动化** | 人性化鼠标移动（曲线轨迹与微抖动；关掉是直线匀速）、自动切换屏幕（默认主屏，打开应用后跟随窗口所在显示器） |
| **媒体生成** | 图片生成 / 视频生成各选一个模型；默认项显示「平台默认（{模型}）」，改过则标「已覆盖」 |
| **运行环境** | **多媒体理解**：ffmpeg 是否就绪，点「管理」看详情、重新检测或让助手安装；**终端环境变量**：给 Agent 的终端子进程加 `KEY→VALUE` 覆盖 |
| **执行** | 并行与上限、内容上限、终端超时，见下表 |
| **工具使用权限** | **自动执行**（AI 用工具时直接跑）或**敏感操作确认**（涉及文件、命令等操作时先问你） |

### 执行：并行与上限

| 项 | 说明 | 默认 |
| --- | --- | --- |
| **工具并行** | 同一轮里多个工具一起跑；关掉则一个一个执行 | 开 |
| **通用工具** | 同一轮里读文件、前台终端、搜索等可同时执行的数量（后台终端不算） | `min(8, CPU 核数)` |
| **子 Agent** | 本会话同时运行的子 Agent 上限，前台与后台共用 | 同上 |
| **媒体工具** | 同一轮里同时进行的图片、视频、多媒体理解数量 | 同上 |
| **轮次 · 本轮** | 这一轮里最多连续调用多少次工具 | 5000 |
| **轮次 · 子任务** | 每个子任务内部最多连续调用多少次工具（子任务面向小范围工作，上限 500） | 500 |
| **任务并行 · 同时任务数** | 同时能跑几条独立任务；聊天、定时、Webhook 共用，同一会话仍排队 | 4 |

点「**查看队列**」能看到当前待执行与排队情况。

### 执行：内容上限与终端超时

工具回给 AI 的内容是有上限的 —— 超了只保留截断后的部分（终端是保留末尾）：

| 项 | 管什么 | 默认 |
| --- | --- | --- |
| **上传（MB）** | 对话里上传文件的大小上限，不含视频 | 100 |
| **正文（KB）** | 一次读取文件时返回的正文上限 | 64 |
| **单行（字节）** | 读文件或搜索时，一行最多保留多少字节 | 1024 |
| **搜索条数** | 一次搜索最多返回多少条结果 | 50 |
| **终端（KB）** | 终端命令每路输出回给 AI 的上限 | 16 |
| **终端超时 · 空闲（秒）** | 命令没指定超时时用这个；这段时间没有新输出就结束命令，有输出会重新计时 | 30 |
| **终端超时 · 最长运行（小时）** | 命令从启动到强制结束的最长墙钟时间 | 24 |

> 工具自己传的参数**只能往下调**，不能突破这里设的上限。

## 连接

四个 Tab：**微信 / 飞书 / 企微 / 钉钉**。每个通道先勾「启用」，再选接入方式：

| 方式 | 说明 |
| --- | --- |
| **扫码连接** | 用对应 App 扫码确认（微信扫码仅桌面端可用） |
| **手动填写凭证** | 飞书填 App ID / App Secret；企微填 Bot ID / Bot Secret / WSS 地址；钉钉填 Client ID(AppKey) / Client Secret；微信没有手填，只能扫码 |
| **高级设置** | 飞书 / 企微 / 钉钉可改用 Webhook 回调模式（需要下面的公网 Base URL） |

「通用设置」对所有通道生效：

| 项 | 说明 |
| --- | --- |
| **IM 出站推送** | 控制 Agent 运行过程中推送到 IM 的消息；最终回复一定会发，工具进度只推「开始调用」 |
| **会话重置（分钟）** | 空闲多久自动开新会话，**默认 60**，`0` 表示关闭；在 IM 里发 `/new`、`/reset`、「新对话」也可以手动开新的 |
| **公网 Base URL** | 通道用 Webhook 模式时生成平台回调地址用 |
| **配对审批** | DM 策略为配对模式时，陌生用户会收到配对码，在这里输入并批准 |

## 技能、插件、MCP

| 分区 | 要点 |
| --- | --- |
| **技能** | 顶部按**执行智能体**分三个 Tab（通用助手 / 氛围编程 / 电脑操控），每个 Tab 有独立的启用集；可按来源筛选（全部 / 用户 / 内置 / 外部 / 插件）、按名字搜索、导入 zip。插件带来的技能不能手动切换，由插件管理 |
| **插件** | 每行一个状态：**未授权 / 校验失败 / 已启用 / 已禁用 / 需重新授权 / 运行异常**；桌面端可从「导入插件」菜单选导入目录或导入 ZIP 文件。检测到外部插件时会有横幅提示一键导入 |
| **MCP** | 添加服务时二选一：**连接远程服务（http）** 填服务地址与可选访问令牌，或 **启动本机程序（stdio）** 填启动命令（高级设置里可加命令参数与环境变量）。每个服务可「查看工具」，工具列表就是它能给 AI 的能力 |

## 调试、用量、关于

| 分区 | 内容 |
| --- | --- |
| **调试** | 保存每轮对话请求（写到本地调试日志）、原始内容查看（助手消息上多一个「原始输出」入口）、标记截图查看（Computer 用的标注截图预览）。三个默认都关 |
| **用量** | 时间范围：今天 / 昨天 / 最近一周 / 最近一月；显示合计与输入、输出，下面是按时间、模型、智能体的明细表 |
| **关于** | 当前版本；托管版桌面端还有「检查更新」，发现新版本后可「立即更新 / 稍后 / 跳过此版本」。见 [官方包与本地构建](which-build.md) |

## 常见问题

**「服务 ID 已存在，请换一个 ID」**

模型配置里服务 ID 本机唯一。换一个 ID 即可，它只用于本机区分服务，不影响调用。

**「请填写服务 ID、名称和 API 地址」**

自定义服务这三项必填，缺一个保存不了。

**「找不到要更新的服务商，请取消后重新编辑」**

编辑期间这个服务被删掉了。取消弹窗、刷新列表，再重新编辑。

**「未检测到」/「未就绪：缺少部分组件」**

运行环境里的多媒体理解没就绪。点「管理」看详情，可以「重新检测」，也可以点「让助手安装」让它自己装。**IM 视频与抽帧理解依赖本机 ffmpeg**，单个视频仍可能因编码或文件损坏抽帧失败，这不代表没装好。

**「暂无环境变量覆盖，点击「添加」新建」**

终端环境变量还是空的。加一行 `KEY` / `VALUE` 即可，保存后持久化；它的优先级高于进程环境变量和 `.env`。

**技能开关点不动**

那是个插件带来的技能。它由插件统一管理，要改就先去「插件」分区处理那个插件。

**「插件 {name} 校验失败，无法启用」**

插件没通过校验，处于「校验失败」状态，不能启用。重新导入一个通过校验的版本，或直接卸载。

**改了设置没生效**

分两类：语言、显示类开关**立即生效**；模型服务的参数是**保存后**生效。执行类的数字（上限、超时）也是保存后生效。
