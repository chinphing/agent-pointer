# 外部工具服务（MCP）使用说明

> 面向 **Pointer 终端用户**。讲如何在设置界面直接添加外部工具服务（MCP server），
> 让对话可以直接调用外部服务提供的工具。
> 插件内声明的 MCP server 见 [`plugins.md`](plugins.md)。

---

## 1. 是什么

「外部工具服务」（MCP server）是**别人或你自己提供的一组工具**，通过统一协议暴露给 AI。
添加后，这些工具会出现在对话里，模型可以直接调用——不用安装插件。

Pointer 是 **MCP 客户端**：你只需提供服务地址（或本机启动命令），它负责连接、握手、
列出工具、调用工具。

## 2. 添加服务（界面直接配置）

1. 打开**设置**
2. 左侧列表找到 **「MCP」（描述：外部工具服务）**
3. 右上角点 **「添加服务」**
4. 选择连接方式，填写字段，点 **「保存」** → 立即生效

### 连接方式一：连接远程服务（推荐，最常用）

适合使用**别人提供的 MCP 服务**（或你自己部署在服务器上的服务）：

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 服务名称 | ✅ | 给这个服务起个名，对话中识别它用 |
| 服务地址 | ✅ | 完整 URL，**端口写在 URL 里**，例如 `http://192.168.1.10:3000/mcp`、`https://mcp.example.com/mcp` |
| 访问令牌 | 可选 | 服务方提供的 API 令牌，会自动作为 `Authorization: Bearer <令牌>` 发送 |

### 连接方式二：启动本机程序

适合**自己开发的服务**（本地脚本 / 可执行文件）：

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 服务名称 | ✅ | 给这个服务起个名 |
| 启动命令 | ✅ | 程序或脚本路径，例如 `/usr/local/bin/my-mcp` 或 `python3 server.py` |
| 命令参数 | 可选 | 空格分隔，例如 `serve --port 8080`（在「高级设置」里） |
| 环境变量 | 可选 | 每行一个 `KEY=VALUE`，例如 `TOKEN=replace-me`（在「高级设置」里） |

## 3. 管理服务

- **编辑**：点服务行右侧的铅笔图标，修改后保存，配置立即更新并重连
- **删除**：点服务行右侧的垃圾桶图标，配置移除、会话关闭
- **刷新状态**：重新获取各服务当前运行状态
- **重启服务**：重新启动所有已配置的服务（状态异常时使用）

服务状态含义：

| 状态 | 含义 |
|------|------|
| 正常 | 已连接，工具可用 |
| 已中断 | 连接/进程中断，正在按退避策略自动恢复 |
| 运行异常 | 连续失败达到上限，已停止自动恢复（可点「重启服务」手动恢复） |
| 未启用 | 已配置但未启动 |

## 4. 配置保存在哪

所有配置保存在**本机用户配置**中（`user_settings.json`），**不依赖任何服务器配置文件**。
重启应用后自动恢复。

## 5. 常见问题

**Q：声明了服务后，还需要再添加客户端吗？**
不需要。Pointer 本身就是客户端，添加的服务就是客户端连接配置，保存即连接。

**Q：怎么填端口？**
stdio（本机程序）不需要端口；远程服务把端口写在 URL 里（`http://host:port/path`）。

**Q：连不上远程服务？**
检查：① URL 是否完整（含端口）；② 服务是否已启动、防火墙是否放行；③ 需要令牌的服务是否填了访问令牌。
界面会显示具体错误信息，可据此排查。

**Q：插件里声明的 MCP 服务怎么用？**
插件作者把服务声明在插件清单（`pointer-plugin.toml`）的 `[[mcp_servers.server]]` 里，
你**启用插件**后自动连接，不需要在「MCP」面板手动添加。详见 [`plugins.md`](plugins.md)。
