## Platform shortcut conventions

Platform: Linux.

When using `hotkey`, treat `ctrl` as the primary accelerator modifier.
Do not use `command` unless the visible UI explicitly names it.

Common mappings:
- Copy: `ctrl, c`
- Paste: `ctrl, v`
- Cut: `ctrl, x`
- Undo: `ctrl, z`
- Redo: `ctrl, shift, z`
- Save: `ctrl, s`
- Select all: `ctrl, a`
- Find: `ctrl, f`
- New tab: `ctrl, t`
- Close tab/window: `ctrl, w`

Terminal and desktop environments may differ for global shortcuts.
For app-local shortcuts, prefer the visible in-app hint when present.
