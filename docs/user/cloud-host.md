# 云主机

仅**官方签名包**且已登录官网账户后可用。社区构建没有购买入口。

桌面客户端可购买并打开云端 Pointer 实例，在独立窗口中使用远程 Web UI 对话。

## 使用前

1. **设置 → 账户** 完成 OAuth 登录
2. 确保账户有余额或已绑定支付方式（以产品界面为准）

## 常用操作

| 操作 | 说明 |
|------|------|
| **设置 → 云主机** | 查看余额、实例列表 |
| **购买** | 创建新云实例 |
| **打开** | 签发 OAuth code，在新 WebView 窗口加载远程控制台 |
| **切换到云窗口 / 关闭云窗口** | 回到本地主窗口继续本地对话 |
| **续费 / 释放** | 在列表中管理实例生命周期 |

关闭云窗口后，本地主窗口对话不受影响。

## Web 端附加能力

在 cloud 实例的 Web UI 中还可：

- 下载与预览聊天附件
- **查看桌面**：侧栏按钮捕获云主机屏幕快照
