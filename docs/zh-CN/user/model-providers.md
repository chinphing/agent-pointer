# 配置模型服务

[English](../../en/user/model-providers.md) | 简体中文

Pointer 的代码里**不打包任何模型服务商**。模型从哪来，取决于你用的是哪种包：

| 你用的是 | 模型从哪来 | 要自己配吗 |
| --- | --- | --- |
| **官方包**（登录平台账号） | 平台**下发**服务商（千问、深度求索等） | **不用** —— 登录后开箱可用 |
| **本地构建 / 自建服务端** | 没有平台下发 | 要 —— 自己填 |

## 服务商分两类

在 **设置 → 模型配置** 里管理：

| 类型 | 从哪来 | 能不能改 |
| --- | --- | --- |
| **平台服务** | 登录平台账号后由平台下发 | **只读** —— 由平台统一维护 |
| **自定义服务** | 你自己添加 | 可增删改，支持任何 OpenAI 兼容接口 |

列表里标着 **平台默认** 的，表示当前生效的服务商。

> 自建部署（standalone）的实例里，「平台服务」的位置显示为「本实例模型服务」，参数与能力和自定义服务相同。

## 接自己的模型：添加自定义服务

**设置 → 模型配置 → 自定义服务 → 添加服务**

| 字段 | 说明 |
| --- | --- |
| **服务类型** | 决定默认参数与协议细节（与内置的千问 / 深度求索同类） |
| **服务 ID** | 本机唯一标识。重复会提示「服务 ID 已存在，请换一个 ID」 |
| **服务名称** | 列表里显示的名字，随便起 |
| **API 地址** | OpenAI 兼容的 base url。请求会打到 `{API 地址}/chat/completions` |
| **API Key** | 服务方给的密钥 |
| **模型列表** | 这个服务下你能用的模型名 |

**服务 ID、名称、API 地址三项必填**，缺一个保存不了。

填完先点**测试连接**确认能通，再保存。

## 两层参数：服务商默认 + 各模型单独

Pointer 的参数是**两层**的，这点和很多工具不一样：

```
服务商默认参数          ← 这一层是兜底
  └─ 各模型单独参数      ← 这一层可选，覆盖上一层
```

- **服务商级**：编辑服务时设置的默认参数与能力
- **模型级**：在模型列表里对**单个模型**点「配置」，单独设参数和能力；点**恢复默认**就回到「跟随服务商默认」

**只配一层就够用。** 只有当某个模型需要不一样的参数时才用模型级。

## 模型能力：决定它出现在哪

**模型能力**是勾选项，**勾了才会出现在对应场景的模型列表里**：

| 能力 | 勾上之后 |
| --- | --- |
| 视觉 | 能读图片 |
| 语音 | 能听音频 |
| 图片生成 | 能出图 |
| 视频生成 | 能出视频 |

**模型在下拉列表里找不到，先回来检查这里。**

## 思考强度

每个模型可以单独设**思考强度**：

```
off → low → medium → high → max
```

调高会让模型在回答前思考更久，适合难题；日常用低档更快。

还能填**扩展参数（`extra_body`）** —— 透传给服务商的原始 JSON，用于服务商的私有字段。

## 设为默认与档位映射

### 默认全局服务商

列表里点**设为默认**，之后新建对话默认用它。

### 场景档位

**设置 → 智能体 → 场景档位**：每个场景（通用助手 / 氛围编程 / 电脑操控）**独立选档**，点「模型」可以调整**各档位对应的模型**。

弹窗里标着「**已覆盖**」的，表示这个档位的模型被手动改过，不是默认值。**改动即时生效**，和「智能体 → 场景档位」联动。

联网搜索的档位模型单独配（**智能体 → 更多工具**）。

## 常见问题

**发送消息提示未配置 Key**

没有任何可用的模型服务。按上面的步骤加一个自定义服务，或者登录平台账号。

**测试连接失败**

- 检查 API 地址：要填 **base url**，不要带 `/chat/completions`（程序会自己拼）
- 检查 Key 有没有多余空格
- 检查网络能不能通到那个地址

**模型不出现在下拉里**

回到**模型能力**，确认勾了对应能力 —— 没勾的模型不会出现在场景列表里。

**服务 ID 重复**

换个 ID。ID 只在本机用于区分服务，不影响调用。

**改了参数没生效**

参数是**保存后**生效的；如果只改了模型级参数，确认保存的是那个模型而不是服务商。
