### locate_element

把「描述」变成「坐标」。**不点击、不输入、不改变桌面状态** —— 它只回答
目标在当前截图里的位置。

**输入**

```json
{"elements": [
  {"description": "地址栏右侧的刷新按钮"},
  {"description": "『文件』菜单里的『另存为』", "hint_box": [800, 35, 840, 55]}
]}
```

- 单个 `elements` 数组，每项一个 `description`，可选一个 `hint_box`。
- **最多 3 项**。超过 3 项直接报参数错误；请拆成多次调用。
- `hint_box` 是 4 个**逻辑像素**值 `[x1, y1, x2, y2]`，是你对目标的初步估计，
  **不是最终点击坐标**。只有当你确实看到目标大致在哪时才传。

**输出**

```json
{"results": [
  {"ok": true, "status": "located",
   "summary": "已找到「地址栏右侧的刷新按钮」并确认位置，坐标 (820, 45) 是元素中心，可直接用于点击。",
   "description": "地址栏右侧的刷新按钮", "x": 820, "y": 45,
   "box": [800, 35, 840, 55], "confidence": "high",
   "what_i_saw": "圆形箭头图标", "rounds": 2},
  {"ok": false, "status": "failed",
   "summary": "没有在当前画面找到「『文件』菜单里的『另存为』」。不要用猜测的坐标点击；先滚动、切换页面或等待加载，再重新定位。",
   "description": "『文件』菜单里的『另存为』",
   "reason": "not_found", "what_i_saw": "当前截图中未能可靠确认目标"}
]}
```

**先读 `status` 和 `summary`**，那是给你的结论：

| `status` | 含义 | 下一步 |
| --- | --- | --- |
| `located` | 找到了，`x` / `y` 是准确位置 | 直接用 `x` / `y` 点击，**不要再定位一次** |
| `failed` | 没找到或没确认 | 按 `summary` 说的做，不要猜坐标 |

- 结果**按输入顺序**返回，一项失败不影响其他项。
- 坐标是**逻辑像素**，与截图同宽同高，和坐标类工具同一空间。
- `x` / `y` 是框中心，可直接用于点击。
- 只有 `status: located` 的项才有 `x` / `y` / `box`。
  **`failed` 的项不得用来点击** —— 不要拿失败项去猜坐标。

**看到 `located` 就不要再调一次**

`located` 已经包含「目标确认 + 坐标可点」两层结论。界面没有变化时重复调用
`locate_element` 只会拿到同一个结果，浪费时间。

**失败后怎么办**

- `reason: "not_found"`：当前画面里找不到。先滚动 / 切换页面 / 等加载，
  再看新截图重新定位；不要连续用同一描述重试。
- `reason: "not_verified"`：候选框始终没通过校验。换一种更有区分度的描述
  （加周边锚点、加文字内容）再试。
- `reason: "unclear"`：画面太糊或被遮挡。先让界面稳定（等加载、关弹窗）。

**什么时候不用它**

- 用户明确给出了坐标。
- 坐标来自刚才某次 `locate_element` 的成功结果，且界面没有变化。
