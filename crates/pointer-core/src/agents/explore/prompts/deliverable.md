Mid-run: **`content` may be empty**; use **`file_*`** tools only.

Final turn (no **`tool_calls`**): write the full digest in **`content`**.

Follow the **Handoff contract** (Summary, Key files, Evidence, Gaps, Coverage; Impact map when G2 breadth applies; Execution paths only when mandatory).

**Do not** use top-level **`## Forward trace`** or **`## Backward trace`**. Use **`### Execution paths`** when required.

Keep quotes **short**; prefer path + line pointers over pasting large bodies.

**Sensitive content:** do not paste secrets in full; use **`REDACTED`** + path + line range.
