再把结论回写到 [`enterprise-admin-console.md`](../enterprise-admin-console.md) §9。

## 实现状态

已按图实现：登录（含验证码）、概览（趋势图 + 最近操作）、资源页（搜索/筛选/分页/
授权选择器/建时可见范围/测试连接/详情抽屉）、角色与权限（自定义角色 + 权限矩阵）、
档位映射矩阵（场景 × 三档，含每格思考强度）、电脑操控定位链（槽位 × 全局/三档）。

## 与图不一致的地方（有意为之）

| 位置 | 图 | 实现 | 原因 |
| --- | --- | --- | --- |
| 右上角头像 | 圆形头像，无菜单 | 同图，点开弹出身份 / 语言 / 退出登录 | 图里没有退出入口，界面上必须有一个；挂在图上的头像上是唯一不改动版式的位置 |
| 顶栏搜索 | 概览「搜索成员 / 资源」、资源页「搜索资源名称」、角色页没有 | 同图；另给成员页加了「搜索姓名或账号」（图里没有成员页） | 成员页是列表页，没有搜索只能靠翻页 |
| 全站文案 | 中文 | 中文 / English 可切 | 与客户端一致；图是中文稿 |
