Search the public web when you need external facts before planning.

**When to call**
- User asks about live data, URLs, or names you do not know.
- You need to confirm app names, versions, or official docs.

**When not to call**
- The user already gave enough context.
- You are replanning an in-scope running board.

**After success**
- Synthesize findings, then init or replace if still needed.
