# 参考框的边界

参考框在这张图里的四条边：**左 {x1}、上 {y1}、右 {x2}、下 {y2}**（图内 0–1000，和你要输出的坐标同一套刻度）。

**这四条边就是图里那圈洋红内圈的位置**（洋红外面还有一圈青色，青色在内圈之外 4 像素左右，不算边界）。用数字是为了让你算得准，用眼睛估会偏。

**这是参考框的边界，不是目标的边界。** 它的用处是让你知道「上一轮说某条边偏了」指的是哪条线、要往哪挪多少 —— 不要靠目测去估参考框有多大、在哪。

如果上一轮说的是「收小到只覆盖某一格」，就按这四条边算：参考框的左 {x1}、上 {y1}、右 {x2}、下 {y2} 围出的区域里，目标占哪一部分。
