## Desktop / vision inject (computer profile)

Before your turn the host injects `[CUR_SCREEN]` with full-screen **before action** / **after action** when both exist, then **`[Annotated after action]`** and **`[Zoom … after action]`** views (indices and magnified strips on the after-action desktop only); pointer/caret may be drawn; older vision images are stripped. Prefer overlay indices with tools such as **`mouse:click_index`** or **`composite_action:type_text_at_index`**; exact labels are listed in the inject (`[Screen before action]`, `[Screen after action]`, `[Annotated after action]`, `[Zoom top after action]`, …). XML invocation examples for **mouse** and other desktop tools are in each tool’s description in the tools list.
