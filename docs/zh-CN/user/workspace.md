# 界面与工作区

[English](../../en/user/workspace.md) | 简体中文

界面分四块：左边是**侧边栏**（项目与会话），中间是**对话**（顶栏 + 消息流 + 输入区），右边是**工作区面板**（文件、Git 变更、终端）。

**工作区**就是这一轮对话绑定的那个本地目录 —— 智能体的读写、终端命令都发生在它里面。

```
┌──────────┬────────────────────────────────┬──────────────┐
│ 侧边栏    │ 对话顶栏：项目 / 工作区选择器     │ 工作区面板*   │
│  ├ 工作台 ├────────────────────────────────┤  ├ 工作区文件 │
│  ├ 项目   │ 消息流                          │  ├ 变更文件   │
│  └ 最近   │                                 │  └ 调试终端   │
│          ├────────────────────────────────┤              │
│          │ 输入区：附件 / 智能体 / 档位     │              │
└──────────┴────────────────────────────────┴──────────────┘
   * 桌面端 + 管理员账号 + 窗口宽 ≥ 1024px 才有这一列
```

## 侧边栏

最上面是**工作台四入口**，一键跳到常用位置：

| 入口 | 去哪 |
| --- | --- |
| **新建任务** | 开一个新会话（已选项目时建在项目下） |
| **定时任务** | 设置 → 自动化 |
| **技能** | 设置 → 技能 |
| **连接** | 设置 → 连接 |

下面依次是项目、置顶、最近：

| 区域 | 能做什么 |
| --- | --- |
| **项目** | 悬停出现放大镜可「搜索项目」；`+` 是「新增项目」（填项目名称与项目目录）；每行右侧 `⋯` 菜单有「新建本地任务」「置顶项目 / 取消置顶」「项目设置」「删除项目」 |
| **会话** | 悬停放大镜可「搜索会话」（按内容搜，命中显示「{n} 处」）；标题双击重命名；行右侧可置顶或删除 |
| **最近** | 没有项目归属的会话都在这儿 |

会话行的状态一眼可辨：转圈 = 正在跑；实心点 + 「有新完成」= 后台跑完了还没看。

**右键会话**还有四个动作：

| 菜单项 | 说明 |
| --- | --- |
| 置顶 / 取消置顶 | 把它提到「置顶」区 |
| 重命名 | 等同双击标题 |
| 复制会话 ID | 复制后可用于排查、对日志 |
| 复制工作目录 | 复制这一轮绑定的目录路径 |
| 在访达中显示 | 打开工作目录（仅桌面端；目录为空时不可用） |

删除会话是**两步**的：点「删除」后原地出现「确认删除」和「取消」，再点一次才真的删 —— 不会弹系统对话框。

左下角是「**当前桌面**」（可查看桌面截图）和「**账户**」菜单（设置、外观、余额、登录 / 退出登录）。

## 对话顶栏：项目与工作区

顶栏中间是**项目 / 工作区选择器**，决定这一轮对话在哪个目录里干活：

| 状态 | 表现 |
| --- | --- |
| 还没选 | 显示「选择项目」 |
| 已选 | 显示项目名，或「默认项目」 |
| **有消息之后** | **锁定** —— 按钮变灰，悬停提示「项目已锁定」 |

**锁定是有意的**：会话一旦开始跑，就不能再换目录，否则前后两轮的文件上下文会对不上。要换目录就开新任务。

选择器里可以选「本地目录」（桌面端弹目录选择框）或已有项目；Web 端只显示路径输入框（顶栏在 Web 上没有项目选择器，项目切换走侧边栏）。

> 一个小陷阱：**点已经选中的项目 = 取消选择**（清空工作目录），不是「重新选中」。

顶栏右侧的「**打开工作区**」用来展开右边的面板（桌面端 + 管理员账号才显示）。

## 输入区

| 元素 | 说明 |
| --- | --- |
| **附件** | 回形针按钮、拖放文件、粘贴图片都可以；上传中显示进度，失败可「重传」 |
| **执行智能体** | 选这一轮用哪个执行智能体（通用助手 / 氛围编程 / 电脑操控 等） |
| **档位** | 快速 / 标准 / 高级；旁边的齿轮跳到「智能体」设置页改档位模型 |
| **发送 / 停止** | 空闲时是发送；正在跑时变成停止（悬停提示「停止当前回合并取消全部后台任务」） |

生成过程中继续发消息不会丢 —— 会进**待发送队列**（面板里显示「待发送」），一轮结束后按顺序发。队列面板里可以「移出队列」或「强制发送」。

后台还有任务在跑时，输入区上方会有「后台仍在执行」面板，可以「取消全部后台任务」或只结束某一条。

## 工作区面板

右列三个标签：

| 标签 | 内容 |
| --- | --- |
| **工作区文件** | 文件树。搜索框可「查找文件」；右键文件有「预览文件」「使用默认应用打开」（桌面）、「复制绝对路径」「复制相对路径」「在 Finder 中显示」「刷新文件树」「删除」；删除前有确认弹窗 |
| **变更文件** | Git 变更列表，带变更数徽标；右键可「查看 Diff」或预览。没有变更时显示「没有 Git 变更」 |
| **调试终端** | 真正的终端（xterm）。可以「新建独立 Shell」、左右或上下拆分窗格、重启或结束 Shell；每个标签有自己的目录与环境 |

预览文件会以标签形式开在面板里，可以并排看多个；「仅显示前 1 MB」这类提示表示内容被截断了。

如果目录还不是 Git 仓库，变更标签会给一个「让 Pointer 初始化 Git 仓库」按钮，不用自己敲命令。

## 消息流里能看到什么

| 元素 | 说明 |
| --- | --- |
| **工具卡片** | 每个工具调用一张卡，状态有执行中 / 完成 / 失败 / 已取消 / 已拒绝 / 等待你的输入 / 等待确认；可以展开看参数与结果 |
| **折叠过程** | 连续的调用会被折成一组，标题可「展开过程 / 收起过程」 |
| **子 Agent 框架** | 子任务单独框起来（「子任务过程」），里面还能嵌套 |
| **思考面板** | 「思考过程」可折叠展开 |
| **原始输出** | 想看模型原始返回时，展开「原始输出」有推理、正文通道原始、工具调用参数三段 |
| **复制** | 每条消息右下角「复制」，复制后变「已复制」 |
| **图片** | 点开可缩放（滚轮缩放 · 拖拽移动 · 双击恢复 · Esc 关闭） |
| **音频** | 可播放；带转写的会显示文字稿 |
| **媒体画廊** | 生成的图片 / 视频可「下载」「打开」「复制文件路径」 |
| **任务板气泡** | 复杂任务会显示进度（{完成}/{总} 里程碑），可展开看步骤 |
| **修改摘要** | 一轮里改过文件时显示「修改了 {n} 个文件」 |

## 页内搜索与会话导航条

| 功能 | 怎么用 |
| --- | --- |
| **页内搜索** | `⌘/Ctrl+F` 在已加载的消息里查找，显示「1/3」这样的计数；`Enter` 下一个、`Shift+Enter` 上一个、`Esc` 关闭 |
| **会话导航条** | 对话右侧那条细竖条，每个你的回合一个刻度；标过里程碑的回合是**菱形**。悬停有预览，点一下跳过去 |

`⌘/Ctrl+F` 有三个地方会抢：对话页内搜索、工作区**文件树**查找、文件预览里的查找。光标/焦点在哪块，就归哪块 —— 在工作区面板里按它，优先给文件树或预览用。

## 紧凑模式

用「电脑操控」跑桌面任务时，窗口会收缩成一条**紧凑状态条**（Dock 样式的横条，只留状态和「终止」「展开」），把屏幕让给被操作的软件。任务结束或切换会话会自动恢复。

这是**桌面端**的行为；Web 端没有这个收缩。

## 移动端

窄屏（宽度 < 768px）下的变化：

| 变化 | 说明 |
| --- | --- |
| 侧边栏收起 | 窄屏不显示侧边栏，顶栏也没有展开按钮 —— 移动端以单个会话为中心 |
| 工作区面板 | 宽度 < 1024px 时不显示 |
| 输入区 | 回形针挪到输入框左侧，智能体 / 档位工具行收起 |
| 新会话按钮 | 会话很长（LLM 调用超过 30 轮）时右下角出现「新会话」按钮，点了会确认「将切换到一个新的会话。当前会话会保留在历史记录中，不会丢失。」 |

## 常见问题

**「项目已锁定」**

这个会话已经有消息了，不能再换工作目录。要换就开一个新任务。

**「当前环境不支持目录选择，请手动填写目录路径」**

Web 端没有系统目录选择框。直接填路径，或改用桌面端。

**「工作目录为空」/「网页端不支持在 Finder 中显示」**

「在访达中显示」需要桌面端且会话绑定了目录。

**「当前目录不是 Git 仓库」**

变更标签依赖 Git。点「让 Pointer 初始化 Git 仓库」即可，或者自己 `git init`。

**「请先在输入区选择项目目录，工作区文件与 Git 变更会显示在这里。」**

还没选工作区。用顶栏的项目 / 工作区选择器选一个目录。

**「没有找到匹配的会话」**

会话搜索搜的是内容。换个关键词，或者清空搜索看全部。

**按 ⌘/Ctrl+F 没反应**

光标在终端里时，`Ctrl+F` 归终端用；页内搜索只对已加载的消息生效，欢迎页上没有它。
